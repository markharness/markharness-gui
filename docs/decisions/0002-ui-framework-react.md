# 0002: UIフレームワークは、Reactとする

## ステータス

Accepted(2026-10-03決定)。

## 背景

フロントエンドは、TypeScriptで書き、ビルドして成果物に埋め込む。実行時には、Nodeを必要としない。必要な画面は、要素の木と関係の表示、2つのコミット間の差分、カバレッジの表、そして、編集のフォームである。実行形態は、[0001](0001-runtime-shell-tauri.md)のとおりTauriで、フレームワークの選択とは独立している。

## 決定

UIフレームワークは、Reactとする。ビルドには、Viteを使う。

関係の画面(木やグラフ)と、編集のフォームで、既存のライブラリを使える。spikeでのReactを含むViteのビルド出力は222KBで、サイズの上限(30MB)に対して、ランタイムの大きさは、問題にならない。

## 代替案

- **Svelte**: 小さく、速く、記述が少ない。ただし、木・グラフ・フォームのライブラリが、Reactより少ない。
- **Solid**: 小さく、速く、Reactに近い書き方ができる。ただし、利用者とライブラリが少ない。
- **フレームワークなし**: 依存はゼロだが、フォームと状態の管理を、自前で書く必要がある。

## 影響

- テストは、ロジックにVitest、画面の部品にReact Testing Libraryを使う。
